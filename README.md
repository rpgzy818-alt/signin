# 签到会 · signin

面向 50–300 人小型活动的开源报名与签到核销工具。一场活动用完即止，数据留在自己的服务器，不强制年费订阅。

An open-source sign-up and on-site check-in tool for small events. Self-hosted, no subscription.

---

> **状态**：v0.1.0 开发中。核心代码正在从内部版本剥离，`backend/` 与 `frontend/` 目录尚未填充，暂不可运行。进度见 [Roadmap](#roadmap)。

## 它解决什么问题

办一场两百人的沙龙，你可能已经在这种状态里：

- 用表单收完信息，签到还要靠 Excel 一列列对
- 现场靠纸笔或群里接龙，事后说不清谁到了谁没到
- 商用会务系统按年订阅，一年只办一两场，成本摊不平
- 客户手机号留在第三方平台，想导出还得看人脸色

这个工具把"报名 → 凭证 → 扫码核销 → 补录 → 导出台账"做成一条直线，一个容器、一个数据库、一个后台。不追求千人大会的并发，也不做会员积分体系。

## 适合谁

**适合**：50–300 人的单场活动——沙龙、义诊、家长课堂、客户答谢会、企业内部分享、招生宣讲。需要扫码签到和导出台账，自己有服务器或愿意租一台。

**不适合**：千人以上会展、需要在线支付与分销票务、长期 CRM 与会员积分、医疗诊断类用途。

## 功能

基础功能完整，不设功能限制：

- 活动展示页：介绍、日程议程、定位导航、主题配色
- 报名表单：字段自定义、提交后可修改、附件上传（图 ≤2、文档 ≤1、单文件 ≤5MB）
- 参会凭证：自动生成带唯一编码的二维码
- 现场核销：扫码核销、人工核销、现场补录
- 时段闸门：签到、补录、核销三个写入口受时间窗控制，报名提交不受限
- 数据导出：报名名单、签到记录、核销明细导出 Excel
- 权限分权：主办方 / 核销员两种角色
- 风控词库：全站展示文本的敏感词拦截

不含：在线支付、多机构租户、看板分析、讲师管理、伴手礼、自定义域名。这些是官方托管版的增值部分，与开源版相互独立。

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | FastAPI + Uvicorn | 单进程，无消息队列 |
| 数据库 | PostgreSQL 16 / SQLite | SQL 方言适配层，两地都能跑 |
| 前端 | 原生 HTML / CSS / JS | 无框架、无 npm，构建脚本用 Python |
| 部署 | Docker Compose | 一条命令起 app + db |

前端不用框架是刻意的：改一个字段提示语不需要装 node_modules。

## 本地开发

后端：

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp ../.env.example .env      # 填数据库连接
uvicorn main:app --reload --port 8080
```

前端构建（把骨架和片段合成产物）：

```bash
python3 scripts/build.py            # 构建全部
python3 -m http.server 8098 --directory frontend
```

构建产物 `frontend/index.html`、`frontend/js/app.js` 等不入库，改完源码要重跑。

## 目录结构

```
backend/            后端
├── routers/        接口层：public 报名 / staff 核销 / admin 后台
├── db.py           建表与迁移
├── form.py         动态表单内核
└── checkin_core.py 核销写入（三条入口共用一套幂等实现）
frontend/
├── public/         参与者端骨架
├── admin/          后台骨架
├── flows/          页面片段：signup / checkin / staff / admin
├── core/           共用 JS 与样式
└── img/
migrations/         数据库初始化 SQL
sample-data/        示例活动与虚拟报名数据
scripts/            build.py 构建、verify_*.py 闸门
docs/               部署与运维说明
```
